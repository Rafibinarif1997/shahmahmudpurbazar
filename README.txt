SHAHMAHMUDPUR BAZAR — FINAL POLISHED MASTER
============================================
Upload every file in this ZIP directly to the GitHub repository ROOT.
No folder is required.

This package includes the marketplace homepage, compact mobile layout,
19 categories, category/subcategory filters, search, price and area filters,
post-ad flow, account/profile pages, favourites, messages, seller details,
Hijama appointment page, admin demo, and mobile bottom navigation.

IMPORTANT:
This is a GitHub Pages-ready client-side demo. Browser localStorage is used
for demo data. It is NOT secure production authentication. For a real public
marketplace, connect a backend such as Supabase Auth + Database + Storage + RLS.
